## 📖 О программе

**PhotoResizer** — простая и быстрая программа для изменения размера фотографий с сохранением качества.

Программа позволяет уменьшать и увеличивать изображения, обрабатывать сразу несколько файлов и работать на популярных операционных системах.

### Основные преимущества

- ⚡ Простая и быстрая работа
- 🖼️ Изменение размера фотографий
- 🔍 Умное увеличение изображений
- 📦 Пакетная обработка файлов
- 🎨 Сохранение качества
- 💻 Поддержка Windows, macOS и Linux
