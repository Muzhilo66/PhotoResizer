# 🖼️ PhotoResizer

**PhotoResizer** — бесплатный кроссплатформенный инструмент для быстрого изменения размера, обрезки и обработки изображений.

Версия **1.1.0** получила готовые пресеты размеров для социальных сетей, умную обрезку и улучшенное интеллектуальное масштабирование.

## ✂️ Умная обрезка — Smart Crop

PhotoResizer умеет автоматически определять важную область изображения при изменении соотношения сторон.

Возможности:

- 🎯 автоматическое определение важной области;
- 🖼️ сохранение ключевых элементов изображения;
- ⚖️ сохранение композиции при изменении пропорций;
- ⚡ быстрая обработка больших изображений.

## 🛠️ Установка

### 🪟 Windows

1. Удалите предыдущую версию PhotoResizer, если она установлена.
2. Скачайте `PhotoResizer_Setup.exe`.
3. Запустите установщик.
4. Следуйте инструкциям на экране.

### 🍎 macOS

1. Удалите предыдущую версию PhotoResizer, если она установлена.
2. Скачайте `PhotoResizer-macOS.zip`.
3. Распакуйте архив.
4. Переместите `PhotoResizer.app` в папку **Applications / Программы**.
5. Запустите приложение.

### 🐧 Linux

1. Скачайте `PhotoResizer-Linux.zip`.
2. Распакуйте архив.
3. Откройте терминал в папке программы.
4. Сделайте файл исполняемым:

```bash
chmod +x PhotoResizer
```

5. Запустите программу:

```bash
./PhotoResizer
```
